# Changelog – XCX Web Interpreter v2.1.0

## [2.1.0] - 2026-09-01

### Fixed
- **JIT**: Fixed JIT-to-JIT function calls (e.g. calling `fib(i)` from inside a JIT-compiled `for` loop): arguments were passed as wrapped `RuntimeValue` objects instead of raw JS values, so the compiled function never hit its base case and recursed until a stack overflow (`RangeError: Maximum call stack size exceeded`). The fibonacci example now runs correctly, and naive `fib(35)` completes in ~80 ms.
- **Errors**: JIT execution now converts genuine stack overflows into a friendly `RuntimeError: Stack overflow: too much recursion in 'fn()'` instead of leaking the raw JavaScript stack trace; the terminal no longer prints `✓ execution finished` after a failed run.

### Changed
- **Versioning**: Target language version updated to XCX 4.3 across the playground (statusbar, terminal banner, About page). Introduced a central version module (`frontend/src/config/version.ts`) used by all UI surfaces. The playground and its bundled interpreter now share a single version: **2.1.0**.
- **Terminal**: Added `!version` command (alias `!v`) showing the language and interpreter version; removed the unprefixed `version` command so all REPL commands share the `!` prefix.
- **Explorer**: Replaced native `confirm()` dialogs with styled in-app modals for file/folder deletion and workspace reset.
- **Theme**: Redesigned the light theme to match the xcx-site palette — cream background, charcoal text, dark-red accent and warm syntax colors; the editor now blends into the page background and the terminal gets a subtle maroon tint. Added shared color tokens (`--text-bright`, `--code-text`, `--terminal-dim`) and made theme switching recolor instantly instead of letting elements fade at different rates.

### Cleanup
- Removed unused Jest dependencies (`jest`, `ts-jest`, `@types/jest`) from the interpreter package; the test suite runs via the native `.xcx` runner.
- Removed an accidentally committed Vite build artifact (`frontend/vite.config.ts.timestamp-*.mjs`).
- Corrected stale golden outputs in the `.xcx` test runner (include tests now expect the actual float-accumulated values, e.g. `4.000000000000004` instead of `4`).
